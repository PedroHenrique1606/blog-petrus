## 💻 Projeto

Este projeto é um site completo com CRUD, login, recuperação de email e envio de emails para gerenciamento de pessoas. O projeto simples, porém contando com várias funcionalidades, foi criado com o intuito de praticar lógica de programação e criar bases sólidas e escaláveis de arquitetura e engenharia tanto a nível de Back-End como a nível de Front-End

- [Visite o projeto online](https://petrus-web.vercel.app/registrar)
- [Visiste a documentação do Back-End](https://petrus-api.onrender.com/docs)

## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- React Vite
- Typescript
- Tailwind CSS
- Postgress
- Docker
- NestJS
- Render (Deploy do Back-End)
- Neon (Banco de dados)
- Vercel (Deploy Front-End)
- Café


## ⚠️ Atenção

A hospedagem do projeto foi feita de forma gratuita usando Render e Neon, por isso, depois de um tempo de inativação o Render fecha a conexão, só sendo reativada quando alguém voltar a usar. Por isso, ao testar, peço a paciência de esperar alguns minutinhos para o servidor iniciar novamente
